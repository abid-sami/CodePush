# CodePush

A modern code and file upload platform where users can upload code snippets or drag & drop files directly to a GitHub repository.

## 🌐 Live Demo

https://codepush.vercel.app

---

## ✨ Features

- Manual code upload
- Drag & drop file upload
- Upload files directly to GitHub repo
- File size limit: 10MB
- Dark mode toggle
- Responsive modern UI
- Fast deployment using Vercel
- Clean and user-friendly interface

---

## 🛠 Tech Stack

- React
- JavaScript
- GitHub API
- Vercel

---

## 🚀 How It Works

1. Upload code manually or select files
2. Files are processed by the application
3. Data is uploaded directly to the connected GitHub repository
4. Files are stored securely in the repository
